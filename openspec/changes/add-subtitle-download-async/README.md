# 字幕下载接口提案摘要

## 📋 提案概述

本提案旨在为 yt-dlp API 项目添加异步字幕下载接口，将现有的同步字幕下载功能扩展为支持批量处理和任务跟踪的异步系统。

### 核心价值
- **异步处理**: 解决长时间字幕下载阻塞API的问题
- **批量支持**: 支持一次下载多种语言的字幕
- **任务跟踪**: 提供完整的任务状态管理和进度监控
- **架构一致**: 与现有视频下载系统保持100%兼容

## 🎯 核心功能

### 1. 异步字幕下载
- **新端点**: `POST /download-subtitles`
- **任务管理**: 与现有任务系统完全集成
- **状态跟踪**: pending → completed/failed
- **文件下载**: 复用现有 `/download/{task_id}/file` 端点

### 2. 批量语言支持
- **多语言下载**: 一次请求最多10种语言
- **自动选择**: 智能选择最佳可用字幕
- **优先级**: 人工字幕 > 自动字幕
- **文件组织**: 按语言分别存储

### 3. 格式支持
- **支持格式**: SRT、VTT、ASS、SSA
- **格式转换**: 自动转换格式（未来版本）
- **降级处理**: 格式不可用时提供替代选项

## 🏗️ 技术架构

### 数据库设计
```sql
-- 最小化变更，仅添加2个字段
ALTER TABLE tasks ADD COLUMN task_type TEXT DEFAULT 'video';
ALTER TABLE tasks ADD COLUMN subtitle_config TEXT;  -- JSON配置

-- 性能优化索引
CREATE INDEX idx_tasks_type ON tasks(task_type);
CREATE INDEX idx_tasks_type_status ON tasks(task_type, status);
```

### API设计
```python
# 请求格式
POST /download-subtitles
{
    "url": "https://youtube.com/watch?v=xxx",
    "languages": ["en", "zh", "es"],
    "auto_select": true,
    "subtitle_format": "srt"
}

# 响应格式（与现有API一致）
{
    "status": "success",
    "task_id": "uuid-string"
}
```

### 核心原则
- **复用现有代码**: 最大化利用现有的 `download_subtitle()` 和 `get_video_subtitles()` 函数
- **保持一致性**: API响应格式完全遵循现有模式
- **最小化变更**: 数据库schema变更最小化
- **向后兼容**: 现有功能完全不受影响

## 📊 性能目标

### 响应时间
- **API响应**: < 200ms (任务提交)
- **字幕提取**: 2-10秒 (根据视频长度)
- **文件下载**: < 1秒

### 并发处理
- **并发任务**: 10个字幕下载任务
- **请求频率**: 5请求/分钟/IP
- **峰值QPS**: 5-10

### 资源使用
- **内存**: < 100MB per字幕任务
- **CPU**: < 50% (正常负载)
- **磁盘**: < 10MB/s I/O
- **网络**: < 1MB/s
